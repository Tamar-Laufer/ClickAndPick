## 🚀 About The Project

In today's fast-paced world, many items are bought for single-use or sit unused in storage. **Click & Pick** addresses this by creating a localized, global-style sharing economy. 
Users can easily create profiles, upload items they no longer need or are willing to lend, and browse a comprehensive catalog of resources offered by others. 

### ✨ Key Features
* **User Authentication:** Secure registration and login system for community members.
* **Item Management:** Users can upload items with descriptions, categories, and availability status.
* **Search & Filter:** Advanced querying to quickly find specific items within the community.
* **Responsive UI/UX:** A modern, clean, and commercial aesthetic designed for seamless navigation across all devices.
* **Status Tracking:** Keep track of which items are currently available, borrowed, or given away.

## 💻 Tech Stack

The platform is engineered using the **MERN Stack**, carefully selected for its performance, scalability, and robust ecosystem:

### Frontend
* **React.js** - Utilized for building a dynamic, component-based user interface that responds instantly to user interactions.
* **Modern CSS/Styling** - Ensuring a clean, professional look without unnecessary clutter.

### Backend & Database
* **Node.js** - Providing a fast, event-driven JavaScript runtime for the backend server.
* **Express.js** - Handling RESTful routing and middleware integration.
* **MongoDB** - A NoSQL database chosen for its flexibility in managing diverse item categories and user profiles.

---

## 🛠 Technical Architecture & Highlights

This project was built with a strong emphasis on clean code, software architecture, and modern best practices:

* **Advanced Asynchronous Flow:** Conducted extensive structural refactoring to transition all client chains and server-side requests to modern `async/await` syntax. This ensures smooth, readable, and highly efficient data fetching.
* **Robust Database Modeling:** Meticulous design and configuration of MongoDB schemas, enforcing data integrity while maintaining the flexibility needed for a dynamic resource-sharing platform.
* **RESTful API Design:** A highly organized and scalable API structure that cleanly separates concerns between the client and server.
* **Error Handling:** Comprehensive error catching and validation mechanisms on both the client and server sides to ensure a stable user experience.

## ⚙️ Getting Started

To explore the code or run this project in your local development environment, follow these instructions:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) and [Git](https://git-scm.com/) installed on your machine. You will also need a MongoDB database (local or MongoDB Atlas).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tamar-Laufer/ClickAndPick.git
   cd ClickAndPick
   ```

2. **Setup the Backend:**
   ```bash
   cd server
   npm install
   ```
   *Create a `.env` file in the `server` directory and add your environment variables:*
   ```env
   PORT=5000
   MONGO_URI=your_mongodb_connection_string
   ```
   *Start the server:*
   ```bash
   npm start
   ```

3. **Setup the Frontend:**
   ```bash
   cd ../client
   npm install
   npm start
   ```
   The application will automatically launch in your browser at `http://localhost:3000`.
